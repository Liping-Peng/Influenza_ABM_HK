# **Example Scripts for Covasim Flu Modifications**

This folder provides example scripts demonstrating how to run the **modified Covasim framework for influenza**. These scripts illustrate how to set up simulations, configure scenarios, apply interventions, and extract outputs.

---

## Folder Contents

- **`run_Season.py`** – Main simulation script. Users can modify:
  - Parameters for the influenza season
  - Intervention strategies and scenarios
  - Outputs to record
- **`base_func.py`** – Utility functions for:
  - Create a directory for storing simulation results
  - Retrieve baseline vaccination coverage
- **`base_data.py`** – Stores data used in simulations, including disease progression, age distribution for each season.
- **`base_subgroup.py`** – Defines population subgroup functions for targeted interventions
