# **Example**

This folder provides example scripts and datasets demonstrating how to run the modified Covasim framework for influenza.
The examples illustrate how to configure simulations, apply intervention strategies, and extract model outputs.
They are intended to serve as a reference for users to reproduce results and adapt the framework to their own research questions.

---

## Directory Structure

```text
example/
├── README.md       # Instructions for example usage
├── code/           # Example scripts for running simulations
├── data/           # Input datasets for simulations
└── result/         # Example outputs generated by simulations

---

## Contents

### 1. `code/` – Example Scripts
- **`run_Season.py`** – Main simulation script.  
  Users may modify:  
  - Parameters for the influenza season  
  - Intervention strategies and scenarios  
  - Outputs to record  

- **`base_func.py`** – Utility functions for:  
  - Creating directories for storing simulation results  
  - Retrieving baseline vaccination coverage  

- **`base_data.py`** – Stores input data used in simulations, including disease progression parameters and age distributions.  

- **`base_subgroup.py`** – Defines population subgroup functions, supporting targeted interventions.
---

### 2. `data/` – Input Datasets

- **`data_season1.xlsx`**
  
  - Calibration dataset for Season 1
  - Includes age-stratified daily case counts and daily school absenteeism
- **`HAI_distribution.csv`**
  
  - Hemagglutination Inhibition (HAI) titer protection distributions by age group
  - *age_group = 0*: < 15 years
  - *age_group = 1*: ≥ 15 years
- **`vac_coverage.csv`**
  
  - Vaccine coverage by age group during Season 1
- **`Season1_calib_param.xlsx`**
  
  - Calibration results from 40,000 runs
  - Contains: calibration ID, mismatch value, and parameter estimates
    (`LP_base_tip`, `LP_sus_0_25`, `LP_sus_45_65`, `LP_sus_65`, `beta`, `pop_infected`)
  - Sorted by mismatch value (ascending). The top 30 parameter sets are recommended for simulation.

---

### 3. `result/` – Example Outputs

This folder provides representative outputs of baseline scenarios.
They serve as a reference for users to understand expected outputs from the model.

- **`figure/`** – Example plots
  
  - New infections over time
  - Cumulative infections
- **`save_sim/`** – Saved Covasim simulation objects
  
  - Allow reloading of full simulation details, including individual agent states
- **`sims_detail/`** – Summary outputs (e.g., Excel files)
  
  - Metrics at each timestep (e.g., new infections, new vaccinations)

---

## Estimated Running Time

As a reference, a simulation with **7 million population** (scale factor 100, ~70,000 agents) typically requires **20–50 seconds** per run, depending on scenario complexity and infection dynamics.
Actual runtime may vary with hardware and computational resources.
